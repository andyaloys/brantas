Bab 1

Ikhtisar & Tujuan Dashboard

Halaman Dashboard merupakan beranda operasional dan intelijen eksekutif utama pada platform BRANTAS (Basis Relokasi Anggaran & Analisis Tematik Akurat Spasial). Dirancang secara khusus untuk pembuat kebijakan level tinggi (Menteri Keuangan, Dirjen Anggaran, Dirjen Perimbangan Keuangan, dan Bappenas), dashboard ini menggabungkan pemantauan makroekonomi kemiskinan dengan pengawasan alokasi belanja perlindungan sosial (Perlinsos) APBN senilai lebih dari Rp470 Triliun.

Tujuan Strategis: Mengeliminasi ketimpangan fiskal (under-allocation) di kantong kemiskinan ekstrem Indonesia timur, mendeteksi anomali integritas data desil penerima bansos, serta memastikan alokasi APBN konvergen menuju sasaran kemiskinan nasional 7,5% pada tahun 2026.

Aliran Data & Siklus Hidup (Data Pipeline & Lifecycle)

Dashboard memproses data secara asinkron dan reaktif menggunakan fitur Angular Signals dan RxJS. Diagram di bawah mengilustrasikan alur sejak pengguna membuka halaman hingga data dirender:

Langkah 1
Inisialisasi & Query Params
ngOnInit() membaca parameter ?tab=macro atau ?tab=allocation untuk menentukan tab awal.
➔
Langkah 2
Parallel API Ingestion
Mengeksekusi Promise.all untuk 6 endpoint REST backend (Summary, Priority, Corridors, Ranks, Distribution, GeoJSON).
➔
Langkah 3
Reactive Signal State
Menyimpan respons API ke dalam signals (summary, priorityRegions, corridors, dll.).
➔
Langkah 4
Render GIS Map (Leaflet)
Jika Tab 1 aktif, poligon 514 kabupaten diinjeksi ke GisChoroplethAdapter dengan pewarnaan klaster spasial.
➔
Langkah 5
Render Charts (ECharts)
Membangun visualisasi kuadran scatter dan garis trajektori RPJMN 2026 di luar zona Angular (runOutsideAngular) demi performa 60 FPS.
➔
Langkah 6
Auto-Cycle & Kiosk Listeners
Memantau event window:resize, perubahan tema dark/light, serta mode layar penuh command center.
Bab 3

Tab Switcher & Mode Tayang Command Center (Auto-Cycle)

Dashboard mengorganisasikan informasi kompleks ke dalam dua perspektif terfokus:

  • Tab 1: Peta Spasial & Indikator Makro ('macro') — Fokus pada sebaran wilayah rentan, agregat angka kemiskinan nasional, dan intelijen ringkasan strategis.
  • Tab 2: Matriks Kuadran & Wilayah Prioritas ('allocation') — Fokus pada efisiensi belanja fiskal per jiwa miskin, radar kuadran ketepatan sasaran, kurva proyeksi sasaran nasional, dan kartu aksi penanganan daerah defisit bantuan.
Mode Tayang Otomatis (Auto-Switch 12s): Dilengkapi indikator Mode Tayang Auto-Switch Aktif (12s) yang secara otomatis beralih antar-tab setiap 12 detik, sangat ideal untuk operasional TV Wall di Command Center Kemenkeu/Bappenas tanpa memerlukan interaksi mouse terus-menerus.

Anatomi Tab 2: Matriks Kuadran Alokasi & Trajektori RPJMN

Tab 2 menyajikan analisis alokasi anggaran daerah melalui 2 grafik analitik visual ECharts beresolusi tinggi:

Chart 1: Matriks Kuadran Kebutuhan vs Alokasi

Scatter matrix 38 provinsi yang menguji apakah alokasi anggaran perlinsos per jiwa miskin (sumbu Y) sejalan dengan tingkat kemiskinan daerah (sumbu X):

  • Defisit Kritis (Merah): Kemiskinan tinggi, pagu rendah (misal: Papua Pegunungan, Papua Tengah).
  • Perlu Afirmasi (Kuning): Kemiskinan di atas rata-rata (misal: Maluku, NTT, Aceh).
  • Sesuai Kebutuhan (Teal): Kemiskinan moderat dengan alokasi proporsional (misal: Jateng, Jatim).
  • Melampaui Rerata (Biru): Kemiskinan rendah namun pagu tinggi (misal: DKI Jakarta, Bali, Jabar).

Chart 2: Trajektori Target RPJMN 2026

Line chart multi-kurva yang mengevaluasi keberhasilan intervensi formula afirmatif BRANTAS dibandingkan dengan target nasional:

  • Realisasi Historis BPS (2021–2025): Tren aktual dari 10.14% turun lambat ke 8.85%.
  • Simulasi Formula BRANTAS (2025–2027): Proyeksi penurunan tajam menuju 7.43% (2026) dan 6.82% (2027).
  • Garis Sasaran RPJMN 2026 (7.5%): Batas keberhasilan nasional yang berhasil ditembus oleh skenario afirmasi IKW.

Spesifikasi Backend REST API Endpoints

Daftar endpoint backend .NET Web API (Brantas.Api) yang dikonsumsi secara langsung oleh komponen Dashboard:

Metode HTTP Endpoint URI Fungsi Layanan Data Payload Output Utama
GET /api/v1/dashboard/summary Ringkasan indikator makro nasional totalBudget, averagePovertyRate, totalPoorPopulation, totalValueAtRisk
GET /api/v1/dashboard/priority-regions 5 provinsi kemiskinan tertinggi Daftar objek: region, povertyRate, poorPopulation, humanDevelopmentIndex
GET /api/v1/dashboard/corridors Agregasi 6 koridor spasial kepulauan Daftar objek koridor, rata-rata kemiskinan, total pagu belanja per kepulauan
GET /api/v1/dashboard/regency-ranks Ranking kemiskinan kabupaten/kota topPoverty[] dan lowestPoverty[] 514 kabupaten
GET /api/v1/dashboard/distribution Distribusi desil alokasi bansos Distribusi bucket frekuensi alokasi anggaran
GET /api/v1/spatial/geojson/kabupaten Peta poligon spasial tematik daerah FeatureCollection GeoJSON batas administratif 514 daerah
POST /api/v1/pipeline/run Sinkronisasi ulang pipeline data Memicu re-generasi data sintetis & re-evaluasi model anomali
